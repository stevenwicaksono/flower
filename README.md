# Turtle Flower 🌸

Awalnya cuma iseng main `turtle`, eh ternyata jadi bunga. Lumayan lah,
jadi kusimpen di sini.

## Cara jalanin

```bash
python main.py
```

Butuh Python 3 sama Tkinter (biasanya udah bawaan). Tunggu sampai
gambarnya kelar, terus klik jendelanya buat nutup.

## Gimana cara kerjanya

Intinya cuma satu kelopak yang digambar pakai dua busur 90°. Kelopak itu
diputer 45° terus diulang 8 kali, jadinya satu lingkaran kelopak. Habis
itu ukurannya digedein dikit, warnanya diganti, dan diulang lagi sampai
7 lapis.

## Coba utak-atik

- `col` buat ganti warna
- `range(7)` buat nambah atau ngurangin lapisan
- `80+n*20` buat ngatur ukuran kelopak
- `t.lt(45)` buat sudut putarnya. Coba 30 atau 60, bentuknya langsung beda.
